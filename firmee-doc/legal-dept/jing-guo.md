# ５　経過

### 事件の経過を時系列で記録

「経過」機能は、様々な情報を事件や連絡先に紐付けて記録できる機能です。「電話対応記録」「期日の結果」「会議の議事録」など、様々な用途にご利用いただけます。

### 経過の作成

トップバーの「＋新規」メニューや、事件詳細ページの「新規」ボタンから作成できます。

作成した経過は、関与者に通知できます。

### 経過の一覧

#### 事件ごとの経過

事件詳細ページでは、「経過」欄に直近の経過のタイトルと本文の一部が表示されます。全てを確認したいときは「一覧へ」をクリックします。

#### 全事件横断の経過

トップページ・トップバーの「経過」をクリックすると、事件横断ですべての経過を確認できます。

### 経過の検索

一覧ページからは、「件名」「内容」を対象として全文検索が行えます。

「詳細」検索からは、日付（範囲）検索も可能です。

### CSV出力・印刷

経過データはCSV出力や印刷が可能です。一覧ページ上部の「CSV出力」「印刷」ボタンからご利用ください。

### 法務専用経過エクスポート

通常の経過エクスポート（9項目）に加えて、関連事件の詳細情報を含む13項目のエクスポートが利用できます。

#### エクスポート項目（13項目）

| #  | 項目名    | 説明           |
| -- | ------ | ------------ |
| 1  | 日時     | 経過の日時        |
| 2  | 送受     | 送信/受信の区分     |
| 3  | 相手先    | 相手先名         |
| 4  | 相手電話番号 | 相手先の電話番号     |
| 5  | 件名     | 経過のタイトル      |
| 6  | 内容     | 経過の本文        |
| 7  | 関連事件   | 紐付けられた事件名    |
| 8  | 監査報告対象 | 「対象」または「対象外」 |
| 9  | 事件名    | 関連事件の事件名     |
| 10 | 訴額     | 関連事件の訴額      |
| 11 | 相手方    | 関連事件の相手方名    |
| 12 | 関連連絡先  | 紐付けられた連絡先名   |
| 13 | 作成者    | 経過の作成者名      |

経過一覧画面に表示される「事件経過エクスポート」ボタンからご利用ください。検索条件を設定した状態でエクスポートすると、検索結果のみが対象となります。

CSV形式（UTF-8 BOM付き）でダウンロードされ、Excelで正しく開くことができます。
