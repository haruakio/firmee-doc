# ９　一括インポート機能

### 既存データをまとめてインポート

firmeeでは、事件データや連絡先データをCSV形式で一括インポートできます。既存のシステムからの移行をスムーズに行えます。

### インポート対象

* **連絡先**：個人・法人の連絡先情報をCSVで一括登録できます。
* **事件**：事件データをCSVで一括登録できます。

### 連絡先インポート

連絡先一覧ページの「CSVインポート」から実行できます。

#### 対応形式

* UTF-8形式（おすすめ）
* 筆まめ形式

#### 対応項目

分類、管理番号、フリガナ、氏名、住所、TEL、FAX、会社名、受任経緯、優先度、預かり物、敬称、旧姓、生年月日、メモ、携帯、e-mail、部署、役職名、URL、区分、関与担当部署ID、関与担当者IDなど。

{% hint style="info" %}
インポート前に、姓名の間に半角または全角のスペースが入っていることを確認してください。スペースがない場合、すべてが姓として扱われます。
{% endhint %}

### 事件インポート

事件一覧ページの「CSVインポート」から実行できます。インポート方法の詳細は遷移先をご覧ください。
