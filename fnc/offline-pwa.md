# オフライン利用（アプリのインストール）

firmeeはPWA（Progressive Web App）に対応しています。スマートフォンやパソコンにfirmeeをインストールしてアプリのように起動でき、画面の表示も速くなります。インストールしたアプリから起動した場合は、直近の事件を端末内に自動で保存し、電波の届かない場所でもオンライン時と同じ画面で閲覧できます。

## インストールのしかた

* **iPhone / iPad（Safari）**：firmeeにログインした状態で共有ボタンを開き、「ホーム画面に追加」を選びます。「Webアプリとして開く」はオンのままにしてください（オフにするとブラウザのタブとして開き、オフライン用データの準備が行われません）。
* **Android（Chrome）**：右上のメニューから「アプリをインストール」または「ホーム画面に追加」を選びます。
* **パソコン（Chrome / Edge）**：アドレスバー右側のインストールアイコンから追加します。

追加されたアイコンからfirmeeを起動すると、ブラウザのアドレスバーがない画面で利用できます。

## オフラインで見られるもの

インストールしたアプリから起動すると、オフライン用データの準備が自動で始まります。

* 更新の新しい事件10件の事件詳細
* その事件に紐づく連絡先・メモ・予定（各事件5件まで）
* 事件一覧（準備した時点の内容）
* 期日・打ち合わせの新規登録フォーム

準備は原則12時間ごとに自動で行われます。

## 自分でオフライン用データを更新する

外出前や期日前に最新の内容を持ち出したいときは、自分で準備を実行できます。ボタンと準備状況は、**事件一覧の上部**と**プロフィールの「設定」→「オフライン」**の2か所に表示されます。

* まだこの端末で有効にしていない場合は**「この端末でオフライン保存を有効にする」**、有効にしたあとは**「オフライン用データを更新」**が表示されます。
* ボタンの下に、最後に確認した日時が「最終確認：◯◯/◯◯/◯◯ ◯◯:◯◯」と表示されます。
* 準備中は「準備中 ◯ / ◯件」と進み具合が表示されます。すべて保存できると「オフラインで利用できます」に変わります。
* 端末の保存容量が足りず一部だけ保存できた場合は「◯件中◯件を保存しています」と表示されます。保存できた分はそのまま閲覧できます。
* オフライン中はボタンを押せません（「オンライン接続後に更新できます」と表示されます）。
* 準備に失敗した場合は少なくとも30分待ってから再試行します。待機中は「次回更新可能：◯◯/◯◯/◯◯ ◯◯:◯◯」と表示され、その時刻まで更新できません。

内容が前回から変わっていない事件は取り直さず、保存できていなかった分だけを補います。

{% hint style="info" %}
自動準備と更新ボタンは、ホーム画面に追加したアプリから起動したときだけ表示されます。通常のブラウザのタブでは自動準備を行わず、ボタンも表示されません。
{% endhint %}

## オフライン中の画面

* オフラインになると、画面左下に「オフライン — ◯月◯日◯◯:◯◯ 時点のデータ」と表示されます。
* 保存されていない画面を開いた場合は、保存済みの事件一覧に切り替わり、画面の上部に「この画面はオフライン用に保存されていないため、保存済みの事件一覧を表示しています。オンライン接続後にもう一度開いてください。」と表示されます。
* 書類・添付ファイル、CSV出力、決済まわりの画面はオフラインでは利用できません。

## オフラインでの期日・打ち合わせの登録

オフライン中でも、期日と打ち合わせの**新規登録**は行えます。

* 登録した内容は端末内に「送信待ち」として保存され、オンラインに復帰すると自動で登録されます。
* 送信待ちの予定は、事件詳細の予定欄に「送信待ち」として表示され、その場で破棄することもできます。
* 添付ファイルを付けた予定は、オンライン接続時に登録してください。

## 保存データの扱い

* 保存したデータは、最終の準備から**7日**で期限切れになります。
* ログアウト、別のユーザーへの切り替え、端末のデータ削除を行うと消去されます。
* いつでもプロフィールの「設定」→「オフライン」から「この端末のオフラインデータを削除」「オフライン保存を無効にする」を実行できます。
* 共有端末でのオフライン保存は推奨していません。
